# DropFit：PDF 液滴图片提取与接触角重分析

这是一个可以直接运行的 Python 项目，不依赖云端模型，不需要 OCR，也不会把报告上的接触角反过来作为拟合目标。它针对侧视背光液滴图像，完成原生图片提取、基准线处理、真实灰度边缘筛选、轮廓拟合、参数敏感性检查以及可审计的报告输出。

**先打开 `demo_results/report.html`，可以直接查看这次上传的19份PDF已经算好的结果，不必先安装Python。** HTML中的图像已内嵌，单独复制HTML也可以离线查看。

## 1. 对这批实验材料的处理约定

液体、材料和原算法以文件名为准。程序不会使用PDF里重复出现的默认“玻璃”“水”字段分类，也不会使用未经确认的截面积、粘附功或表面能。只有原报告中的左角、右角、平均角被作为比较记录提取，不参与拟合初值、目标函数或是否采用结果的判定。

这19份PDF各包含一张790×600像素JPEG。彩色圆、切线、绿色基准线已经写入该JPEG，不能从PDF中无损地“关闭图层”来恢复原始相机照片。程序屏蔽可识别的彩色轮廓点，但不能恢复被遮挡的信息，也不能保证JPEG产生的弱色伪影已经全部消失。

**自动模式沿用报告里的绿色基准线，属于共享基准线的算法复核。** 需要更独立的复核时，用 `annotate` 在图像中重新选取固体表面，并保存选区、基准线和图片哈希。

## 2. 快速运行

推荐Python 3.11或以上。本次实际测试使用Python 3.13.5；精确依赖版本在 `demo_results/manifest.json` 中。

### Windows：按钮方式

安装Python时勾选“Add Python to PATH”。首次双击 `install_windows.bat` 安装到项目内的 `.venv`；之后双击 `run_demo.bat` 重新分析配套19份PDF，或双击 `run_gui.bat` 打开文件夹选择窗口。

安装依赖需要网络；安装完成后的分析不联网。GUI只是任务启动器，人工划基准线使用下面的 `annotate` 命令。当前环境实际运行验证了批处理和核心测试，未对你的Windows桌面进行端到端鼠标操作测试。

### 命令行方式

在项目目录打开终端：

```bash
python -m pip install -r requirements.txt
python -m dropfit batch --input input_pdfs --output my_results
```

分析单份PDF：

```bash
python -m dropfit batch --input "input_pdfs/水-Al-3-theta.pdf" --output single_result
```

分析自己的整个文件夹：

```bash
python -m dropfit batch --input "D:/接触角实验/PDF" --output "D:/接触角实验/重分析结果"
```

路径含空格或中文时加引号。建议保持输入文件名唯一，使用独立输出目录，不要将输出图像重新放回输入目录。程序支持PDF及PNG/JPEG/BMP/TIFF静态图片；没有绿色基准线的原图需要人工指定基准线。对于带针头、多液滴、复杂背景或扫描整页，先人工框选单个液滴；本版不是任意页面的通用物体识别器。

## 3. 人工复核基准线

```bash
python -m dropfit annotate "input_pdfs/水-Al-3-theta.pdf" --config overrides.json
```

窗口打开后，先点击选区的两个对角点：包含完整液滴与足够的基底，排除针头和其他液滴。然后在真正的固体表面上点击相距足够远的两个基准线点；不必恰好点击接触点。点击完成后自动保存，不要按软件原角度调整基准线。

重新分析：

```bash
python -m dropfit batch --input input_pdfs --output reviewed_results --config overrides.json
```

安装在`.venv`时，可把命令里的 `python` 改为 `.venv\Scripts\python.exe`。多页/多图PDF可以附加 `--page 2 --image 1`（从1计数）。选区坐标使用提取出的原生图片像素，不是PDF页面点数、屏幕显示像素或毫米。

自动保存的配置同时包含原生RGB图像SHA-256；更换源图后旧基准线配置会被拒绝，防止无意套用到不同图片。

## 4. 实际实现的拟合方法

主方法是**全轮廓鲁棒圆拟合**。它同时利用可辨认的上轮廓点，并以几何距离残差求圆心和半径，不是重新读取软件的角度，也不是把原图蓝色切线的方向当成答案。圆与给定基准线相交后得到模型表观接触角。它仍然包含球冠/圆形截面的模型假设，不能因残差小就证明真实液滴必定是球冠。

复核方法是**左右局部参数多项式拟合**。圆拟合只提供局部参数坐标，左右轮廓的两个坐标函数分别自由拟合，再求与基准线交点处的切向量。它不是强制局部轮廓仍落在同一个圆上；但会对边缘遮挡、外推距离、窗口和阶数敏感。

同时输出一个高度/宽度几何检查。这里的宽度沿用局部拟合外推的两个接触点，因此不应称为第三次独立测量。数学表达、图像处理细节和可修改参数见 `docs/METHOD.md`。

程序没有实现Young–Laplace/ADSA、椭圆拟合、神经网络分割、视频时间轴拟合或表面能反演。没有长度标定和可靠物性时，不自动生成表面张力或毫米单位的面积/体积。

## 5. 输出文件

`report.html` 是含数值、自动审计结论和全部诊断图的离线报告。点击每个文件可展开原图与拟合叠加、圆模型残差。

`results.csv` 是UTF-8 BOM表格，可导入Excel；`results.json` 保留更完整的模型、基准线、每一项参数扰动和质量标记。`conclusions.md` 由数据和质量标记生成审计结论，`summary.md` 给出汇总表。`fit_summary.tex` 是可插入实验报告的小节，需要中文LaTeX环境及 `booktabs`、`longtable`；其候选值与状态不能不经复核直接当作最终实验数据。

`images/编号_哈希/` 中保存每个原生提取图 `source.png`、叠加诊断图 `diagnostic.png`、残差图 `residual.png`、源图及基准线坐标下的轮廓 `contour.csv`、单图结果 `result.json`。NA图不会生成虚假的有效轮廓/残差文件。

`manifest.json` 记录依赖版本、配置、运行时间和错误；`errors.json` 记录无法打开的源文件。默认不修改任何输入PDF。

## 6. 如何解释状态与敏感性

|状态|含义|
|---|---|
|CONDITIONAL|在给定基准线与圆形轮廓假设下通过本版筛查；不是已确认的真实平衡角|
|REVIEW|数值候选仍保留用于诊断，但 `reportable_conditional_theta_deg` 为NA，不自动采用|
|NA|未能给出可靠有限角；不等于接触角为0°或证明完全润湿|

判断根据原生像素高度、模型残差、被彩色标线遮挡的比例、局部/全局差异、左右不对称和参数敏感性。没有“酒精一律无效”的规则，也没有“与另一次测量不同就删除”的规则。12 px高度门限是本版保守工程筛查规则，不是小于12 px在一切条件下都不可测的物理定理。

每幅可拟合图片会运行标称参数和9项单因素变化：基准线上/下移动1原生像素；阈值减/加25；基准线附近排除带减/加2像素；局部弧段窗口减/加0.1；二次/三次多项式切换。每次都保存候选角。

范围的含义是**这组指定参数变化造成的结果变化**，不是95%置信区间，不是同一材料重复测量的标准差，也不覆盖所有系统误差。尤其不能把约1°的敏感性范围误称为绝对准确度达到1°。

## 7. 本次数据的实际结果与重要修正

实际运行的19个图像记录中，15个为CONDITIONAL，3个为REVIEW，1个为NA，另有1个精确重复栅格标记。CONDITIONAL数不是独立实验样本数。

- 酒精--Al：原生液滴高度只有数个像素，程序不给出可靠有限角，记为NA。
- 酒精--NKUcard、水--NKUcard的tan图：局部和全局候选角差较大，列入复核；这并不意味着原始读数已经被证伪。
- 水--paper的tan图：局部左右差异较大，列入复核；不能凭此唯一归因为纸张吸液。
- 两份Cglass图的原生RGB像素完全一致，由哈希直接确认；不能当成新增独立样本。
- Al-2的圆拟合约34.9°，Al-3两图约81.7°和82.1°。Al-2图确实呈低角形貌，不能只因它与Al-3差别大就自动弃用。应保留记录并核查液滴、位置、时刻和样品状态；图像重分析不能替代这些实验信息。

上述数值只适用于本次所带数据和默认参数。全量数值、敏感性范围和各图标记以 `demo_results` 为准。

## 8. 自检与复现

```bash
python -m unittest discover -s tests -v
```

本次17项测试全部通过，覆盖坐标变换、正/负基准线移动、锐角/钝角圆模型、含噪轮廓、倾斜基底、彩色基准线、悬空液滴拒绝、薄层拒绝、空图、缺失基准线、文件名解析、像素哈希及“更改原软件读数不改变拟合结果”。日志在 `docs/test_results.txt`。

解析圆模型、模拟栅格和软件单元测试不能替代真实样品的计量校准，更不能证明对所有实验图片达到相同精度。

## 9. 代码结构

```text
contact_angle_project/
  dropfit/
    io.py            PDF原生图像、文本提取；文件名标签
    imaging.py       彩色标记筛除、分割、源灰度边缘提取
    geometry.py      基准线坐标、圆拟合、局部参数多项式
    analysis.py      质量门限、单因素敏感性、结果状态
    outputs.py       CSV/JSON/HTML/TeX和逐图审计
    __main__.py      batch和annotate命令
  run_app.py         可选Tk桌面启动器
  input_pdfs/        本次19份原实验PDF
  demo_results/     已实际运行得到的结果
  docs/             方法、验证说明与日志
  tests/            17项自检
```

原始代码许可见 `LICENSE_CODE.txt`；第三方依赖和实验数据分别保留自身的许可及归属。
