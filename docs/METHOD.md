# 方法与限制

## 数据来源和像素尺度

输入优先为PDF内嵌的原生位图，通过PyMuPDF读取；并非把整页放大后把新插值像素当作新增分辨率。当前19份报告是790×600像素JPEG。确实没有适用的内嵌位图时才回退到页面/图片区域渲染，并加人工复核标记。一个页面存在多张图片时，程序不会把同一段角度文字任意分配给每张图。

PDF中图像的显示变换会被检查。明显的非等比例显示或剪切会产生警告；计算仍使用原生图片。图像拍摄或导出前是否已被非等比例拉伸，无法只凭当前PDF排除。

几何角度在等比例缩放下不变，但在横纵非等比例缩放下会变。后者不能靠“输出更多DPI”修复。所有程序中的长度均是原生图像像素。

## 基准线和坐标

图像坐标x向右、y向下。基准线经过点(x0,y0)，与图像x轴夹角为alpha。定义

    u = cos(alpha)*(x-x0) + sin(alpha)*(y-y0)
    v = sin(alpha)*(x-x0) - cos(alpha)*(y-y0)

v=0为基准线，v>0朝向液滴。这避免把倾斜的样品表面误当成水平线。自动模式通过明显绿色像素的鲁棒直线回归识别原仪器的标线，并在回归内点上复核。这个操作不能验证该标线本来画得是否正确。

没有可靠绿色标线时返回NA/提示人工选线，不以图像中心或最低黑像素冒充实际基准线。手动基准线必须是相隔至少10像素的两个点，并位于真正的固体表面。

## 分割与轮廓筛选

首先采用RGB三个通道的最大值构造灰度检测图，对高饱和蓝、青、品红标线进行抑制。然后用sigma=0.55原生像素的高斯平滑、固定灰度阈值及连通域提取选择基准线以上的暗色液滴。

内部亮斑不能作为液滴的外轮廓。因此，程序只在之后将被排除的近基准线窄带内暂时闭合二值分割，填充连通内部区域以识别外边界。这里没有对原图进行生成式修复或图像插值补全。

在二值边界候选处，必须能找到平滑后的源灰度图中真实跨越阈值的相邻像素，才线性插值得到亚像素坐标。二值闭合、人为填洞和ROI截断产生的虚构边界不能通过这个检查。接近基准线的排除带（默认6 px）不参与任何轮廓拟合。

随后以RGB通道极差大于60识别强彩色污染，剔除对应边缘点。保留和剔除的点都会写入contour.csv。亚像素插值只是连续坐标估计，不意味着真实准确度高于原始光学分辨率。低饱和度的JPEG色漏与被覆盖的真实边缘仍然可能引入系统误差。

当前流程假定一个主要的、暗背景剪影式的静滴，且基底在选区内可用直线表示。曲面叶片、复杂纹理、透明弱对比液滴、多液滴、阴影与针头连通等情况可能需要人工选区或其他分割算法。程序不会将这些限制隐藏为“自动测角成功”。

## 全轮廓鲁棒圆拟合

对筛选后的点(u_i,v_i)，令

    r_i = sqrt((u_i-u_c)^2 + (v_i-v_c)^2) - R

用SciPy least_squares最小化这些几何残差的soft_l1损失，f_scale=1 px。最初值来自一次线性圆拟合，不使用PDF文本中的角度。

圆与v=0相交时，有

    cos(theta_circle) = -v_c/R
    theta_circle = arccos(-v_c/R), 0 < theta_circle < pi

这一定义支持锐角和钝角，不把大于90°的角误折成其补角。圆若不与基准线相交，则不输出可信接触角。

输出的RMSE是普通几何残差平方均值的平方根，不是角度标准差。Jacobian条件数用于识别严重的参数病态。低RMSE也可能来自被原软件圆线影响后的轮廓，故必须同时查看边缘遮挡、残差空间结构和原图。

## 左右局部参数多项式

先借助全局圆心定义一个接触点附近的平滑参数坐标，近似为沿弧段的距离。左右两侧分别自由拟合

    u(q) = a0 + a1*q + a2*q^2 [ + a3*q^3 ]
    v(q) = b0 + b1*q + b2*q^2 [ + b3*q^3 ]

分别求邻近名义接触点的v(q0)=0实根，再计算(u'(q0),v'(q0))。参数增加方向指向液滴上部，因此要求v'(q0)>0。左右角分别计算为

    theta_left  = atan2(v', u')
    theta_right = atan2(v', -u')

两个局部坐标函数没有被约束为同一个圆。全局圆只提供参数化参考；但两种方法仍共享图像与基准线，不能当成统计独立测量。

局部导数和交点属于外推，低角、少像素、高遮挡时可能很不稳定。默认二次多项式不是对所有轮廓最优，三次也不总是更准确；敏感性测试会保留两者差异，不能选一个最接近原报告的阶数作为“验证”。

## 高度/宽度检查

    theta_half = 2*atan(2*h/d)

这里h来自提取的上轮廓高度，d来自两个局部模型外推接触点的距离。它只检查球冠几何一致性，并不是独立复测。球冠模型、对称性和基准线都仍然是条件。

## 质量门限

当前保守筛查：原生高度小于12 px、悬空或错误连通域、ROI裁掉液滴、可靠基准线/轮廓缺失等返回NA。高度门限写在imaging.py中，并非一个经过所有仪器校准的通用标准。

以下主要门限在analysis.py的DEFAULTS集中定义，并可通过JSON defaults覆盖：圆模型RMSE>2 px；轮廓强色污染剔除比例>0.55；局部均值与圆模型差>6°；左右局部差>8°；圆模型参数敏感性跨度>5°。满足任一项将标记REVIEW。局部参数敏感性跨度>10°单独给出说明，不擅自把全部局部数值当作稳定角度。

例如，可以只改变筛查阈值而不改变轮廓拟合：

```json
{
  "defaults": {
    "max_circle_rmse_px": 1.5,
    "max_local_circle_difference_deg": 5.0
  },
  "images": {}
}
```

这些是可审计的工程门限，而非仪器国家标准。调整后必须记录参数，不应为了保留某个预期结果而反复调参。默认参数已统一应用于本次19份报告，未逐文件通过原读数调优。

## 敏感性不等于统计不确定度

程序采用一次改变一个因素的固定扰动，其他参数保持名义值不变。这不是把全部参数组合穷举，也不是蒙特卡洛随机抽样。其最小值、最大值和跨度只描述被测试条件，不具有95%等概率覆盖意义。

这些检查不包括：真实基底弯曲、相机非正视、镜头畸变、物理基准线整体错误、滴液时刻差异、表面非均匀性，以及JPEG叠加之前已经发生的信息损失。真实实验需要同一条件的独立液滴/位置重复测量，不能用同一张图的数百个轮廓像素作材料接触角的独立样本。

## 为什么没有直接加入ADSA

本版没有实现Young–Laplace/轴对称液滴形状分析。该路线需要明确轴对称几何、物性与空间标定以及可辨认的真实轮廓。当前上传材料明确只认可接触角，面积等输出没有可信长度标定，因此程序不会自行补物性或把默认表面能当作已知量，进而制造表面张力和毫米量纲结果。

这不表示未来不能扩展ADSA，而是当前代码明确只声称实现已经测试的几何重分析。
